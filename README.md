Social Media Trend Analysis using Python (Tweepy, TextBlob) and Power BI

# 🌐 Social Media Trend Analysis – Task 1

This project explores **real-time trend analysis** on social media, combining web scraping, Natural Language Processing (NLP), sentiment analysis, and interactive dashboards using **Python** and **Power BI**.

---

## 📌 Project Objective

To identify **trending topics** and analyze **public sentiment** on various social media platforms (Twitter, Instagram and Facebook) offering businesses and organizations insights into market dynamics, user interests, and potential engagement strategies.

---

## 🛠️ Tools & Technologies

- **Python**  
  - `Tweepy` – for accessing live Twitter data via Twitter API  
  - `TextBlob` – for sentiment analysis  
  - `BeautifulSoup` – for additional HTML parsing (if needed)  
  - `Pandas` – for data processing

- **Natural Language Processing (NLP)**  
  - Text cleaning, tokenization, keyword extraction

- **Power BI / Excel**  
  - Interactive dashboard design and visualization

- **Dataset**  
  - https://www.kaggle.com/datasets/kashishparmar02/social-media-sentiments-analysis-dataset
---

## 📊 Project Deliverables

- **Jupyter Notebook:**  
  Full Python pipeline: data collection, processing, sentiment scoring, and word cloud generation.

- **Interactive Power BI Dashboard:**  
  Visualizations of:
  - Top trending hashtags and keywords  
  - Sentiment distribution (positive, neutral, negative)  

- **Screenshots and Visual Assets:**  
  Exported visuals for easy sharing and interpretation

---

## 🧠 Key Insights

- Most conversations centered around **AI**, **mental health**, and **technology trends**
- Sentiment leaned towards **neutral**, with a healthy mix of **positive** tones
- Businesses can monitor these shifts to adjust marketing and communication strategies in real-time
